# UMN-VR/.github

Shared community files for every repository in the
[UMN-VR](https://github.com/UMN-VR) organization. GitHub shows them on each
repository that doesn't have its own copy.

- [Code of conduct](CODE_OF_CONDUCT.md)
- [Contributing](CONTRIBUTING.md), including how versions are named
- [Security](SECURITY.md)
- [Bug report template](ISSUE_TEMPLATE/bug_report.md)
- [Agent instructions](AGENTS.md), which each repository's AGENTS.md points to
